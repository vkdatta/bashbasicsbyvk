ISSUE IN BRIEF
The pickers of Transfer (local and GCloud) and the csv file picker each drew their own header and numbered rows, so they differed from the folder view: no status row, cd path or nav path, no 🔒 marks, different icons (a .zip or an executable showed 📄), a different row indent, and the 'w' tip sat in the footer. Wanted: one pick screen, titled by job, reused by every picker.

HOW DID YOU DEBUG
Read local_navigator / gcloud_navigator (bashbasicsbyvk_transfer.sh), _file_picker (bashbasicsbyvk_csv.sh), _menu_header and display_items / _item_line_text_v (browse.sh, displayer.sh) and grep'd the script tree for printf "%2d)" rows: three hand-written lists plus the staging shortcut registry and the fx selection browser (not touched, see FIX). Ran a harness that sources displayer.sh and the new browse.sh functions and compared _pick_rows with display_items on a temp folder (byte for byte equal; .zip 📦, executable ⚙️) and checked that -r rows carry no lock mark. The real app, the loadmap and the fast tier were NOT run when this note was written (verified by reading and the harness only).

CAUSE
The folder view draws through the global path / items (_menu_header, display_items) and 'open a folder' means 'cd into it', so Transfer, which needs browse plus keep picking across folders, was written with its own copy of the header and the row loop. The copies never received later changes (lock marks, the shared icon table, the status row).

FIX
browse.sh: new _pick_header WHAT JOB NAV [PREFIX] [DESC] (status row, title 'Select <WHAT> for <JOB>', Settings description, cd path, nav path), _pick_rows [-r] PATH... (rows via _item_line_text_v: same icons, 🔒, + marks; -r = remote paths, no locks, no size / time) and _desc_print_dim (the dim wrapped description printer, moved out of _rn_pick_header which now calls it). transfer.sh: local_navigator and gcloud_navigator use them; the 'w' tip moved from the footer into the description (settings_desc.sh keys 'Select items|*' and 'Select destination|*'). csv.sh: _file_picker uses them. tests/pick_drift.sh (pick_drift, fast) fails when a picker file draws its own numbered rows or when _pick_rows differs from display_items. Not converted: _fx_sel_browse / _fx_sel_pick (rows are not a folder listing) and the staging shortcut registry. Lesson: a new picker calls _pick_header + _pick_rows; never printf a numbered row.
