ISSUE IN BRIEF
The Rename and Delete item pickers (and the other flat "choose items, no w prefix" pickers: remove bookmark, remove favourite, rules delete, unorganise, xtr- and i- pick) each drew their own screen: Rename had its own header / footer hooks and a Settings description, Delete used the folder header with the status row, the "DELETE (ranges ...)" footer and the "Item numbers:" prompt. Wanted: one shared screen for all of them: action title, the folder view's location rows, "Select items to <action>", the rows, "u) Up   q) Close", "Select:", and the old per-menu templates removed.

HOW DID YOU DEBUG
Grepped the strings the person sees (Item numbers, DELETE (ranges, Select items to) and every caller of select_items_common / select_imaginary_items_common / _multi_header_hook. Found that only Rename passed header / footer hooks; the others took the default header (_menu_header) and footer of _multi_footer_fn. Auth and xui pickers also use the default footer but are not file-list screens, so they were left alone. Ran bash tests/run.sh (green, 9/9) and the one pty test rename_screen (green); printed the Rename and Delete screens through PtyApp to read the layout. The pty tests nav_test, prompt_test, mouse_test were only edited for the new strings, not run.

CAUSE
The picker chrome was owned by each caller (a hook per screen, plus a default meant for the main list), so the screens drifted.

FIX
browse.sh: _menu_header split into the status rows plus _loc_rows (the cd path / nav path rows, one printer); new _pk_header / _pk_footer / _pk_set (the shared picker screen); select_items_common "<icon> Title" [allow_a] and select_imaginary_items_common PATH PREFIX ["<icon> Title"] use it (the action in the sentence is the title without the icon, lower case); u / q / blank return silently. Callers moved to titles: delete, switch (remove bookmark), favourites (remove favourite), rules (delete), organise (unorganise), extract (xtr-), fileinfo (i-). rename.sh: _rn_pick_header, _rn_pick_footer and _rn_select_items removed (it calls select_items_common). settings_desc.sh: "Rename item|*" removed (no screen shows it). Stubs regenerated. Tests edited for the new strings. Left on the old default footer on purpose: the auth and xui row pickers and the Transfer group step (a flow with its own header). script/choose_test_driver.sh (a stray leftover of a choose test, not in the mapper) was moved out of the tree so the load mapper could regenerate.
