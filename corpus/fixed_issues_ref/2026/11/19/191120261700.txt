ISSUE IN BRIEF
Menu layouts (title block, location rows, "Select items to <action>", footer keys, prompt word) were typed by hand in many places (_pk_header, _pick_header, _mc_header, _mc_menu_n, _st_draw, the "Select:" prompts), and tidy only named a layout without owning it. A template architecture was wanted: one global definer, .sh.tpl layout files named by their tidy ID, one processor, and menu files that only supply data.

HOW DID YOU DEBUG
Read AGENTS.md, tidy.sh / tidy_gen / tidy.list, menuchrome.sh, browse.sh (_pk_header, _loc_rows, _pick_header) and _st_draw. Compared old and new output with a bash harness that extracts the old functions from a copy of the repo and runs both for 11 cases (picker, grouped picker, three pick-screen forms, _mc_header, _mc_menu, _mc_menu0, no header): all byte-identical. The Settings block was compared against a hand-built copy of the old block for 5 desc / hint / footer combinations: identical. Ran loadmap_gen --check and bash tests/run.sh once (10/10). NOT run: pty tests; the real Settings screen, clicks and resize were verified by reading and by the block comparison only.

CAUSE
No single place owned the layout text, so every screen re-typed it and a wording or spacing change had to be repeated. tidy IDs pointed at "kinds" of screen but not at a file a person or agent could edit.

FIX
New folder script/file/templates/: bashbasicsbyvk_tpl_defs.sh (global definer, [fg]: every $section and {placeholder} defined once, incl. {footer_acceptor} = "Select:"), bashbasicsbyvk_tpl.sh (processor, [bg]: _tpl_set / _tpl_clear / _tpl_section / _tpl_render / _tpl_build / _tpl_check), and bashbasicsbyvk_<ID>.sh.tpl for the 8 templates of tidy (373QS6 settings, 7UH852 item picker, MG2374 pick screen (new), YWW6WZ step menu, 7P68NA, JR9TZ5, T5FL4F, V3PX4Y). Wired: _pk_header / _pk_footer (7UH852), _pick_header (MG2374), _mc_header + _mc_menu_n (YWW6WZ), _st_draw (373QS6, built in one write, geometry unchanged), and the prompt word of the main list, _mc_ask, _mc_select, _mc_review and Settings (${_TPL_ACCEPTOR}). _loc_rows split into _loc_cd_row / _loc_nav_row. _MC_KEYLABEL got the named variant q.close. tidy.list: pick-header screens moved to MG2374; tidy_gen checks template files, defined names, unused names, defs-in-templates and adds --show / --placeholders / skeleton creation; tidy prints the template file; t_tidy.py runs _tpl_check through the processor. Lesson: a template must print exactly what the screen printed (blank rows are literal), and fn placeholders run in the current shell (never $( )) because footers declare into the advert registry. Templates 7P68NA, JR9TZ5, T5FL4F and V3PX4Y are declared only; their screens still draw themselves.
